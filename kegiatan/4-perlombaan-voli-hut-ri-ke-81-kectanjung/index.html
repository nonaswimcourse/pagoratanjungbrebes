Perlombaan Voli HUT RI Ke-81 Kec.Tanjung

Selasa, 4 Agustus 2026
Bagikan kegiatan ini
Bagikan WhatsApp

Luwungbata — Langkah tim voli Pagora harus terhenti lebih awal di ajang turnamen voli memperingati HUT RI ke-81. Bermain di Lapangan Voli Luwungbata, Pagora gagal mengamankan tiket ke babak 8 besar setelah menelan kekalahan tipis dari tim Mutiara Bunda dengan skor akhir 2-1.

Pertandingan yang menyedot perhatian warga setempat ini berlangsung sengit sejak set pertama. Kedua tim saling jual beli serangan dengan mengandalkan smash-smash tajam dan pertahanan yang rapat.

Jalannya Pertandingan Set Pertama: Tim Mutiara Bunda tampil menekan sejak awal laga. Mengandalkan kekompakan dan variasi serangan yang ciamik, Mutiara Bunda berhasil mengamankan set pertama dan unggul terlebih dahulu. Set Kedua: Tidak tinggal diam, Pagora bangkit mendominasi jalannya permainan. Memanfaatkan celah di lini pertahanan lawan, Pagora tampil agresif hingga mampu merebut set kedua sekaligus menyamakan kedudukan menjadi 1-1. Set Penentu (Set Ketiga): Atmosfer pertandingan semakin memanas di set penentu. Kedua tim bertarung ketat merebut poin demi poin. Namun, Mutiara Bunda tampil lebih tenang di poin-poin kritis. Memanfaatkan beberapa kesalahan mendasar dari skuad Pagora, Mutiara Bunda akhirnya mengunci kemenangan dengan skor akhir 2-1.

Gagal ke Babak 8 Besar

Kekalahan dramatis ini memastikan Pagora harus angkat koper lebih awal dari turnamen HUT RI ke-81 di Luwungbata. Meski belum berhasil melaju ke babak 8 besar, perjuangan pantang menyerah yang ditunjukkan skuad Pagora tetap mendapat apresiasi meriah dari para pendukung yang memadati area lapangan.

Sementara itu, kemenangan ini membawa Mutiara Bunda melenggang mulus ke babak 8 besar dan kian memperbesar peluang mereka untuk merengkuh gelar juara di ajang tahunan ini.
